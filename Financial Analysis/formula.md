# Basic Functions
For normal statistical analysis we use our arithmatic formulas:
- SUM(range), AVEREGE(range), MAX(range), MIN(range), LARGE(range, k-value), SMALL(range, k-value), ROUND(value, round_value)
- Row wise SUM shortcut is *Alt + =*

# Conditional Functions
For Aggregation using condition, Conditional Functions are used
- COUNTIF(), SUMIF(), IF()
- IFS() for multiple condition
